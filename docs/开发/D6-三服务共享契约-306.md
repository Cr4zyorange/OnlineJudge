# D6 三业务服务共享契约（#306）

公开浏览器 API 保持 `/api/v1/**`。内部服务调用只使用 `contracts/v2/openapi/`；事件只使用 `contracts/v2/asyncapi/events.asyncapi.json`。业务服务本地验证 Identity 的 JWT/JWKS，内部调用使用按 audience 的短时服务身份；禁止共享 `X-Internal-Token`、跨 schema SQL、进程内 callback 作为生产路径。

`EventEnvelope` 固定含 `eventId`、`eventType`、`payloadVersion`、`aggregateType`、`aggregateId`、`aggregateVersion`、`occurredAt`、`correlationId`、`payload`。投递为 at-least-once：消费者在本地事务中记录 inbox、去重 `eventId`、忽略旧版本、记录缺口并执行受控 replay/reconciliation 或进入 DLQ。

Assessment 向 Grade 发布 `assessment.source-grade.changed.v2`；向 Course 发布 `assessment.evaluation.completed.v2`、`assessment.lab.published.v2` 和 `assessment.homework.published.v2`。Grade 向 Course 发布 `grade.published.v2` 和 `grade.review.processed.v2`。这些现有类型已经覆盖 LRN 所需的任务、完成、成绩发布和复核通知事实，因此不新增虚构事件。Course 的课程/成员/公告通知由同一 Course 本地事务处理，不需要跨服务传播。

`status=SCORED` 的来源成绩必须有非负 `number` `score`；`status=UNGRADED` 的 `score` 只能是 `null`。Assessment 写操作同步通过 Course 授权；Course 不可用时返回 503 且不写 Assessment 事实。Grade 正常计算只读本地来源成绩投影。

Identity mint 的 `accessToken` 是 `readOnly`、response-only 字段，request body 不得接受 `accessToken`。作业发布在同一本地事务写 `PUBLISHED` 与 outbox；仅该本地事务失败返回 `HWK_5003` 并保持 DRAFT，消费者使用 `receiverScope`，RabbitMQ/Course 不可用不回滚发布。

`node scripts/ci/verify-microservice-contract-v2.mjs` 与 `node scripts/ci/verify-three-service-baseline-306.mjs` 是当前正向/反向契约门禁；前者校验版本化制品的兼容性反例，后者拒绝独立 Learning 服务、五 schema 或十个工作负载回归。
