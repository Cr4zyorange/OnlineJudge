# 前端重构回归与性能基线

本基线用于前端视觉重构前固定可重复的本地证据：同一组学生、教师演示账号在同一提交上读取课程、任务、实验、作业、成绩和通知，并记录前端生产构建体积及关键 API 的多次 HTTP 状态和耗时。它服务于后续重构任务的 RED/GREEN 对照，不替代自动化测试、浏览器流程验收、FAT/UAT 或压力测试。

## 运行前提

1. 按仓库根目录 `README.md` 启动后端与前端，确认 `http://127.0.0.1:5173/` 可访问。
2. 使用包含演示课程 `9501` 的本地数据库；默认账号为 `student001` 和 `teacher001`。
3. 在仓库根目录运行：

```bash
./scripts/test/collect-frontend-baseline.sh
```

脚本默认先执行一次 `frontend` 生产构建，再对每个指标采样 5 次，结果写入已由 `.gitignore` 排除的 `test-results/frontend-baseline/<时间戳>/`。如需复测部署入口，可显式设置：

```bash
BASE_URL=http://127.0.0.1:8088 \
FRONTEND_URL=http://127.0.0.1:8088 \
SAMPLES=5 \
./scripts/test/collect-frontend-baseline.sh
```

仅当 `frontend/dist` 已由当前提交重新构建时，才可设置 `SKIP_FRONTEND_BUILD=1`。账号密码可通过同名环境变量覆盖；脚本通过标准输入发送登录请求，token 只保存在权限为 `0600` 的临时文件/内存中，并在退出时清理，不写入结果目录。

## 结果解释

| 证据 | 含义 | 不能据此声称 |
| --- | --- | --- |
| `frontend-http.tsv` | 当前运行入口的 `GET /` HTML 响应状态、耗时和字节数 | 浏览器完整首屏传输量 |
| `frontend-assets.tsv` 的 `initial_direct_uncompressed` | 生产 `index.html` 及其直接引用的本地脚本、样式、preload 文件的未压缩磁盘体积 | gzip/brotli 后传输量或懒加载资源总量 |
| `frontend-assets.tsv` 的 `full_dist_uncompressed` | 完整生产 `dist` 的未压缩磁盘体积，含懒加载 chunk 和图片 | 首屏一定会下载这些文件 |
| `api-timings.tsv` | 本机单用户、只读关键 API 的逐次 HTTP 状态、耗时和响应字节数 | 并发容量、生产性能或网络条件下 SLA |
| `summary.md` | p50/p95/max 与设计文档参考线的 smoke 对照 | 正式性能验收结论 |

真实首屏传输量应另用浏览器 Network/HAR，在固定视口、禁用/启用缓存状态明确的前提下记录；不要把入口 HTML、生产首屏直引文件和完整 `dist` 三个口径混为一谈。

脚本只计时登录/退出和只读查询，不提交实验或作业，也不触发评测。若 `environment.txt` 记录 Docker daemon 为 `unavailable`，本轮结果不能声称真实 Docker 沙箱评测可用；即使 daemon 可用，也必须另跑真实评测专项并记录沙箱模式、代码样例、状态流转和总耗时。

## 离线验证

脚本的语法、输出结构、采样数和敏感信息不落盘由本地桩测试验证：

```bash
bash -n scripts/test/collect-frontend-baseline.sh
bash -n scripts/test/collect-frontend-baseline.test.sh
./scripts/test/collect-frontend-baseline.test.sh
git diff --check
```

后续页面重构应在同一提交、相同数据和相同采样设置上保留重构前后两组结果，并同时补充学生/教师关键页面截图和功能、空状态、失败状态、权限状态的浏览器验收记录。
