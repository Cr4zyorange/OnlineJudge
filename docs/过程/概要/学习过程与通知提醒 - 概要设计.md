## 1 模块概述

### 1.1 模块定位

学习过程与通知提醒模块（LRN）为平台核心**行为跟踪与消息触达**模块，负责**学习行为记录、学习进度跟踪、站内通知、消息推送、学习提醒**五大核心能力，为学生 / 教师提供学习状态感知与关键事件提醒，是连接 CRS、LAB、HWK、GRD 模块的消息中枢。

### 1.2 核心职责

- 跟踪学生全流程学习行为（资源访问、实验 / 作业参与、学习时长）
- 统一管理站内通知与消息推送
- 提供学习进度可视化与数据统计
- 向用户推送实验发布、作业截止、成绩发布等系统消息

### 1.3 术语与缩写（审查完成）

已完成 1.3 章节术语审查，确认 LRN 相关术语（LRN、学习记录、通知、站内信）定义准确、统一。

## 2 功能需求（2.5.3）

### FR-LRN-01 学习进度跟踪（P0）

- **角色**：学生、教师
- **核心功能**：学生查看个人课程学习进度；教师查看班级整体学习完成率
- 前端设计要点
  1. 提供**线性进度条、完成率百分比**可视化展示
  2. 按课程 / 章节维度拆分进度，支持进度详情展开
  3. 进度数据实时同步，异常时自动校准

### FR-LRN-02 站内通知系统（P0）

- **角色**：全体用户
- **核心功能**：接收实验发布、作业截止、成绩发布、课程公告等通知，支持未读 / 已读管理
- 前端设计要点
  1. 全局铃铛图标 + 未读红点提醒
  2. 通知列表按时间倒序，区分未读 / 已读样式
  3. 支持单条 / 批量标为已读、删除操作

### FR-LRN-03 通知订阅与偏好设置（P1）

- **角色**：全体用户
- **核心功能**：用户自定义通知接收开关（实验 / 作业 / 成绩 / 公告）
- 前端设计要点
  1. 提供独立设置页面，开关组件可视化
  2. 设置项实时保存，即时生效
  3. 支持一键恢复默认设置

### FR-LRN-04 在线学习记录（P1）

- **角色**：学生
- **核心功能**：查看历史学习记录（资源访问、学习时长、完成状态）
- 前端设计要点
  1. 列表 + 时间筛选器布局，支持按课程 / 日期筛选
  2. 记录项展示学习内容、时长、时间、状态
  3. 长列表采用懒加载，提升渲染性能

### FR-LRN-05 学习时长统计（P2）

- **角色**：学生、教师
- **核心功能**：统计日 / 周 / 月学习时长，生成时长趋势图
- 前端设计要点
  1. 使用 ECharts 展示时长柱状 / 折线图
  2. 支持切换时间维度，数据自动刷新
  3. 教师端支持查看班级平均时长

### FR-LRN-06 讨论与互动（P1）

- **角色**：学生、教师
- **核心功能**：课程内留言、提问、回复互动
- 前端设计要点
  1. 评论区支持富文本输入、表情、图片上传
  2. 支持点赞、回复、楼层展示
  3. 新互动消息自动推送至通知中心

## 7 运行设计（LRN 专属）

### 7.1 运行场景

1. **消息推送**：WebSocket 实时接收 → 更新未读数 → 展示弹窗 / 铃铛红点
2. **学习记录**：用户访问资源 → 前端定时上报 → 生成学习记录
3. **通知操作**：标已读 / 删除 → 本地状态更新 → 异步同步后端
4. **普通跨模块通知落库**：业务事务内调用 `publish` → 注册 after-commit 回调 → 回调只排入专用有界执行器 → 工作线程开启独立事务落库；来源事务回滚时不生成通知，调度或落库失败只记告警
5. **必达通知落库**：业务事务内调用 `publishRequired` → 同步写入通知并加入来源事务 → 任一步失败均向上抛出并回滚来源业务；`HOMEWORK_PUBLISHED` 采用此契约

### 7.2 异常处理

- **网络异常**：本地缓存通知操作 / 学习记录，联网后自动重试
- **推送断开**：自动重连 WebSocket，重连成功后拉取遗漏通知
- **数据异常**：进度 / 统计异常时，提示 “数据加载失败” 并提供刷新按钮

### 7.3 性能要求

- 通知列表首屏加载 ≤ 1s
- 未读红点更新 ≤ 300ms
- 学习统计图表渲染 ≤ 2s
- 长列表滚动无卡顿

## 8 前端专属设计（前端总设计师）

### 8.1 技术栈

- 框架：Vue 3 + TypeScript
- 构建：Vite
- 状态：Pinia（存储未读数、通知设置）
- UI：Element Plus
- 推送：WebSocket
- 图表：ECharts

### 8.2 核心组件

- LrnNoticeCard：通知卡片（全局复用）
- LrnBadge：未读红点（全局挂载）
- LearningProgress：学习进度条
- LearningChart：学习统计图表

### 8.3 状态管理

- `lrnStore`：存储未读通知数、通知设置、当前学习进度
- 持久化：通知设置、未读数存入 localStorage

### 8.4 兼容性

- 支持 Chrome≥90、Firefox≥88、Edge≥90
- 移动端响应式适配，通知列表单列展示
- 低版本浏览器降级：关闭 WebSocket，改为轮询拉取通知
