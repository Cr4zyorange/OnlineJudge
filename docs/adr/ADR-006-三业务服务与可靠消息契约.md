# ADR-006：三业务服务、Identity 支撑与可靠消息契约

- 状态：Accepted
- 日期：2026-09-01
- 决策 Issue：#306

## 决策

业务服务固定为 Course（CRS+LRN）、Assessment（LAB+HWK，API+Worker）和 Grade（GRD）。Identity 是身份支撑，不计入业务服务；Gateway、Frontend、RabbitMQ、MySQL 是基础设施。Course 在同一服务内管理学习任务、进度、提醒和通知，不单独部署 Learning。

Assessment 与 Grade 的跨服务事实使用版本化 outbox/inbox 事件。来源业务事务只提交自己的事实和 outbox；RabbitMQ 或消费者不可用不得回滚。消费者 at-least-once 去重、处理版本缺口、DLQ 和受控重放。Course 通过现有 Assessment 的发布/评测事件和 Grade 的发布/复核事件生成 LRN 通知，没有新增事件类型。

来源成绩的 `SCORED` 为数值分数，`UNGRADED` 的 score 必为 `null`，不伪造 0 分。Identity mint 的 `accessToken` 为 `readOnly`、response-only 字段，request body 不得接收该字段。Homework `PUBLISHED` 与 outbox 同一事务；仅该事务失败返回 `HWK_5003` 并保持 DRAFT，消费者按 `receiverScope` 生成任务/通知。

四个 schema/account 一一对应：`oj_identity`/`oj_identity_rw`、`oj_course`/`oj_course_rw`、`oj_assessment`/`oj_assessment_rw`、`oj_grade`/`oj_grade_rw`。跨 schema SQL、共享 Repository 和全局内部 Token 均被禁止。

## 后果

部署清单为 gateway、identity-service、course-service、assessment-api、assessment-worker、grade-service、frontend、rabbitmq、mysql；迁移顺序为 identity、course、assessment、grade。此 ADR 替代当前树中的五服务 ADR；旧决策仅在 Git 历史保留。
