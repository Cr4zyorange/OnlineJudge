## 1. 使用前准备

### 1.1 访问地址

入口：浏览器访问系统前端地址。

浏览器要求：建议使用 Chrome、Edge、Safari 或 Firefox 的当前稳定版。系统页面需要启用 JavaScript；如使用隐私模式或禁用本地存储，登录态、主题和学习行为缓存可能无法保留。

步骤：

1. 打开 Chrome、Edge 或其他现代浏览器。
2. 输入系统部署地址。Docker Compose 演示在本机启动后可访问 `http://127.0.0.1:8088/`；若部署在局域网服务器或云主机，应使用对应宿主机地址并确认防火墙或安全组已放行入口端口。
3. 系统进入统一登录页面。

预期结果：页面显示“用户登录”和“注册”入口。平台页面采用统一应用外框，登录页顶部保留平台导航栏和头像占位；这不表示用户已经登录，真正的登录状态以表单提交成功后的提示、令牌写入和后续页面可访问性为准。登录成功后，系统按角色开放课程中心、学习任务、通知中心、个人中心和管理页面。

### 1.4 注册、登录与账号安全

入口：`/login` 登录页面、`/register` 注册页面、顶部头像进入个人中心。

步骤：

1. 已有账号时，在登录页输入账号和密码，点击“登录”。
2. 需要创建学生账号时，切换到“注册”，填写账号、显示名称和密码，提交后回到登录页登录。
3. 登录成功后，学生和教师进入课程中心；管理员需要维护用户权限时直接访问 `/admin/auth`。
4. 进入个人中心后，可维护显示名称、手机号、邮箱和头像地址。
5. 在个人中心的“修改密码”区域输入原密码、新密码和确认密码，提交后当前登录会话失效，需要重新登录。

预期结果：注册成功后生成学生账号；登录成功后顶部导航显示平台名称、课程中心、学习任务、通知中心和个人头像；密码修改成功后系统清除当前会话并要求重新登录；无权限访问时系统进入 403 提示页或登录失效提示页。

AUTH 相关页面和状态说明：

| 场景 | 页面入口 | 操作与结果 |
| --- | --- | --- |

| 注册 | `/register` 或图 1-1 中“注册”页签 | 当前版本开放学生自助注册，填写账号、显示名称和密码后创建学生账号；成功后切回登录表单并回填账号。该流程使用认证页同一面板，不另附单独截图。 |

### 1.5 退出登录

入口：顶部导航右侧独立的“退出”按钮。

步骤：

1. 确认当前已经登录，顶部导航右侧显示“退出”按钮。
2. 直接点击“退出”；请求处理中按钮显示“退出中”并暂时禁用，避免重复操作。
3. 退出完成后，重新访问 `/courses`、`/learning/tasks`、`/notifications`、课程实验、作业或成绩等受保护页面。

预期结果：系统撤销当前会话，清理浏览器本地 token，并回到登录页或登录失效提示页。退出后访问受保护页面时，后端返回未认证结果，前端不展示课程、提交、成绩、通知等用户数据，而是提示重新登录。

### 1.7 助教角色说明

本版用户手册不单列助教端章节。助教是课程成员中的协作角色，可由教师或管理员在课程成员管理中设置；其课程内可见入口、作业批阅、实训评分等操作并入教师端说明，实际可操作范围以课程成员角色、平台角色权限和当前页面权限校验结果为准。若助教访问某个教师操作时出现无权限提示，应由课程教师或管理员检查课程成员角色和平台权限配置。


## 2. 学生端操作说明

学生端主流程为：

```text
登录 -> 课程中心 -> 查看课程资源 -> 查看学习任务 -> 提交实验/作业 -> 查看评测反馈 -> 查看成绩 -> 查看通知
```

### 2.1 查看课程中心

入口：顶部导航“课程中心”，路径 `/courses`。

步骤：

1. 使用学生账号登录。
2. 点击顶部导航“课程中心”。
3. 在课程列表中查看本人已加入或可访问的课程。
4. 可使用搜索框按课程名称、学期或分类筛选课程。
5. 若课程尚未加入，根据课程加入方式点击“直接加入”“输入邀请码”或“申请加入”。
6. 加入成功后点击课程卡片进入课程详情；需要审核的课程需等待教师或管理员通过申请。

预期结果：页面展示课程名称、授课教师、学期、分类、课程状态和成员信息。公开课程可直接加入，邀请码课程需输入有效邀请码，审核课程提交后显示待审核状态。学生端主要操作入口是课程卡片中的“进入学习”；课程编辑、归档、成员审核等管理操作仅属于教师或管理员角色。

### 2.2 查看课程主页、公告、章节和资源

入口：课程中心中点击课程卡片，路径示例 `/courses/9501`。

步骤：

1. 在课程中心点击目标课程。
2. 查看课程简介、课程公告、近期任务和课程统计信息。
3. 查看章节目录，确认资源所属章节。
4. 在资源列表中查看资源名称、类型、发布时间和可见范围。
5. 点击资源下载入口获取课件、讲义或附件。

预期结果：学生可以看到课程公告、章节和对学生可见的资源；不可见资源或非成员课程不会向学生开放。

### 2.3 查看学习任务

入口：顶部导航“学习任务”，路径 `/learning/tasks`。

步骤：

1. 点击顶部导航“学习任务”。
2. 查看系统按课程聚合的实验、作业和资源任务。
3. 可按任务类型、状态、课程和截止时间筛选。
4. 点击任务卡片中的跳转入口，进入对应课程、实验或作业页面。

预期结果：任务中心显示任务标题、所属课程、截止时间、完成进度和状态。已完成、未开始、进行中、逾期等状态应有明确标识。

### 2.4 查看学习进度和学习行为仪表盘

入口：顶部导航“学习任务”后进入“学习进度”，路径 `/learning/progress`。

步骤：

1. 进入学习进度页面。
2. 查看课程总进度、章节进度和最近学习位置。
3. 点击“刷新”获取最新学习进度。
4. 点击继续学习入口回到课程、资源或任务页面。
5. 需要查看个人学习行为时，从学习任务页进入“学习行为仪表盘”，路径 `/learning/statistics`。
6. 在“我的学习趋势”中查看近 7 天学习时长、资源访问、任务提交、完成任务和最近学习行为。

预期结果：学习进度页面展示课程数量、课程进度、章节进度、完成状态和更新时间；学习行为仪表盘展示当前学生自己的学习趋势和最近学习行为。学生只能查看自己的学习进度和行为统计。

### 2.6 提交实验并查看评测反馈

入口：实验列表中点击“进入实验”，路径示例 `/courses/9501/labs/950201?role=student`。

步骤：

1. 查看实验说明、截止时间、允许语言、时间限制和内存限制。
2. 在代码或文件提交区域填写实验代码，或按页面要求选择文件。
3. 点击提交按钮。
4. 提交完成后进入提交历史或反馈区域。
5. 查看评测状态、得分、通过用例数、运行日志和教师评语。

预期结果：系统生成一条实验提交记录，并显示自动评测状态。文件型提交会保留该提交版本的源文件元数据，供有课程管理权限的教师核对；学生可查看自己的提交和评测反馈，但本版本不向学生开放源文件下载接口，即使文件由本人提交也不能直接下载。学生不能查看其他学生提交。

### 2.8 提交作业并查看反馈

入口：作业列表中点击作业，路径示例 `/courses/9501/homeworks/950301?role=student`。

## 3. 教师端操作说明

教师端主流程为：

```text
登录 -> 课程管理 -> 维护章节/资源/公告 -> 发布实验/作业 -> 查看提交 -> 评分 -> 配置和发布成绩 -> 查看教学分析/学习统计
```

### 3.1 管理课程

入口：顶部导航“课程中心”，路径 `/courses`。

步骤：

1. 使用教师账号登录。
2. 进入课程中心。
3. 在左侧菜单选择“全部课程”“我的课程”“我管理的课程”或“已归档课程”。
4. 在创建课程表单中填写课程名称、课程简介、学期、分类、加入方式、邀请码、人数上限和课程状态。
5. 点击“创建课程”。
6. 对已有课程可执行编辑、章节、资源、公告、成员等管理操作。
7. 在课程详情中查看选课审核和课程成员，按需通过或拒绝学生申请，调整成员角色或移除成员。

预期结果：教师可创建课程并在课程列表中看到；教师只能管理本人负责或被授权的课程。成员审核通过后学生获得课程访问权限，成员角色调整后权限按课程角色生效。

课程加入审核与成员管理步骤：

1. 在课程中心打开目标课程的“管理课程”入口，进入课程详情或课程管理页；可对照图 3-1 的课程管理区域。
2. 打开“成员”或“选课审核”区域，查看状态为待审核的加入申请。
3. 对符合课程要求的申请点击“通过”。通过后学生成员状态变为有效成员，可进入课程主页、学习任务、实验、作业、成绩和通知相关页面。
4. 对不符合条件的申请点击“拒绝”。拒绝后学生不会获得课程访问权限，课程资源、实验、作业和成绩接口仍按非成员处理；若课程规则允许，学生可重新提交申请。
5. 在课程成员列表中选择已有成员，按教学需要将课程角色调整为学生、助教或教师协作角色。角色调整后，成员在课程内可见入口和可执行操作随课程角色变化。
6. 对退出课程、误加入或不再参与教学的成员执行“移除成员”。移除后该用户不再以课程成员身份访问课程数据；其历史提交、成绩、日志等业务记录按系统数据保留策略继续留痕。

结果影响：通过申请会开放课程内学习和提交权限；拒绝申请不开放课程资源；角色调整会影响课程管理、批阅和评分权限；移除成员会阻断后续课程访问，但不会静默删除既有提交、评测、成绩或审计记录。

预期结果：教师和管理员可查询其有权限课程的学生学习进度聚合，用于判断课程资源学习推进情况、发现进度落后的学生并安排提醒。学生账号不会显示“课程学习统计”区域；无权限课程会返回无权查看提示。

## 5. 常见状态与异常处理

### 5.1 截图中的英文状态说明

部分页面直接展示后端状态枚举。使用时可按下表理解：

| 英文状态 | 中文含义 | 常见位置 |
| --- | --- | --- |
| `SCORE_PUBLISHED` | 成绩已发布，学生可查看对应实验、作业或课程成绩 | 实验列表、作业列表、成绩相关页面 |
| `DOCKER_IO` | 使用 Docker 沙箱按输入/输出用例自动评测 | 实验评测模式 |
| `SUBMITTED` | 已提交 | 实验或作业提交记录 |
| `ACCEPTED` | 自动评测通过，所有公开/配置用例通过 | 实验或代码作业评测结果 |
| `TEXT` | 文本作业或文本提交类型 | 作业详情、作业提交记录 |
| `CALCULATED` | 课程总评已计算完成 | 教师成绩总表 |
| `PUBLISHED` | 已发布，对目标学生可见 | 课程、成绩记录或发布状态 |
| `PARTIAL_STUDENTS` | 按部分学生发布 | 成绩发布记录 |
| `SENT` | 通知已发送 | 成绩发布记录、通知投递状态 |

### 5.2 登录失败

可能原因：

- 账号或密码输入错误。
- 账号已被禁用。
- 会话已过期。

处理方式：

1. 检查账号和密码是否与系统分配一致。
2. 若账号被禁用，联系管理员启用账号。
3. 若提示登录失效，重新进入登录页登录。

### 5.3 无权限访问

可能原因：

- 学生访问教师或管理员页面。
- 教师访问非本人管理课程。
- 非课程成员访问课程资源、实验、作业或成绩。

处理方式：

1. 返回课程中心确认当前账号和角色。
2. 检查是否已加入课程。
3. 需要课程管理权限时联系课程教师或管理员处理。

### 5.4 提交失败

可能原因：

- 作业或实验未发布、已关闭或已截止。
- 文件格式或大小不符合要求。
- 网络异常或评测服务暂不可用。

处理方式：

1. 查看页面错误提示。
2. 检查截止时间、提交类型、文件格式和代码语言。
3. 网络恢复后重新提交。
4. 若评测异常，等待系统重试或联系教师处理。

### 5.5 成绩不可见

可能原因：

- 教师尚未发布成绩。
- 当前账号不是该课程学生。
- 访问了其他学生成绩或未授权课程。

处理方式：

1. 确认成绩页面显示的是本人课程。
2. 等待教师完成发布。
3. 如仍不可见，联系任课教师检查发布范围。

### 5.6 通知未收到

可能原因：

- 通知偏好关闭。
- 业务事件尚未触发。
- 非课程成员无对应通知。

处理方式：

1. 进入提醒规则设置页面检查通知偏好。
2. 在通知中心刷新或调整筛选条件。
3. 联系教师确认实验、作业或成绩是否已发布。

### 5.7 课程为空或学习任务为空

可能原因：

- 当前账号尚未加入任何课程。
- 课程加入申请仍在审核中。
- 教师尚未发布实验、作业或资源任务。
- 当前筛选条件过窄，例如只筛选已完成或已逾期任务。

处理方式：

1. 返回课程中心确认是否已有课程卡片。
2. 对邀请码课程输入教师提供的邀请码；对审核课程等待教师或管理员审核。
3. 在学习任务页清空筛选条件后刷新。
4. 如课程已加入但仍无任务，联系任课教师确认实验、作业或资源是否已发布。

### 5.8 邀请码错误

可能原因：

- 邀请码输入错误、大小写不一致或包含多余空格。
- 课程不是邀请码加入模式。
- 课程已归档、人数已满或不再允许加入。

处理方式：

1. 复制教师提供的邀请码后重新输入，避免手工输入错误。
2. 返回课程卡片确认该课程显示为邀请码加入。
3. 若仍失败，联系教师确认课程状态、人数上限和最新邀请码。

### 5.9 文件上传失败

可能原因：

- 作业附件为空、超过 10 MiB，或扩展名、MIME、文件内容签名不一致。FILE 作业只允许 `pdf, zip, docx, xlsx, pptx, txt, md, csv, png, jpg, jpeg`。
- 已上传但超过 24 小时未提交绑定，或该附件已绑定/已删除。
- 网络中断或登录态已过期。
- 部署环境上传文件卷不可写或容量不足。

处理方式：

1. 检查页面提示，确认文件格式、大小和作业/实验要求一致。
2. 作业附件上传失败时，页面应保留当前选择；直接点击重试。要更换文件时点击移除后重新选择。
3. 若提示过期或状态冲突，移除原记录并重新上传；不要复制旧 `fileId`。
4. 重新登录后再次上传，或更换网络环境。
5. 若多名用户都上传失败，联系运维检查部署环境的上传文件卷和后端日志。

### 5.9.1 实验提交源文件无法下载

可能原因：

- 当前账号不是目标课程的可管理教师或管理员；学生本人也没有本期下载权限。
- 该提交没有源文件。
- 历史提交只有旧文件标识，缺少可信文件名、内容类型或大小；页面会显示元数据不可用提示。
- 资产已删除、文件卷未恢复、文件损坏或存储读取失败。

处理方式：

1. 确认从教师实验提交详情页的“下载源文件”入口操作，没有把“下载实验报告”当作源文件入口。
2. 确认当前教师对目标课程具备管理权限，并核对实验和提交版本。
3. 遇到历史元数据不可用提示时，不尝试拼接静态地址；联系管理员核对原始备份。
4. 页面提示源文件暂时无法下载时，联系运维按部署文档检查 DB-LAB-09、上传文件卷和存储根目录。

### 5.9.2 作业提交附件无法下载

可能原因：

- 当前账号既不是该提交的学生，也不是目标课程管理者。
- 会话已过期，下载请求重新鉴权时被拒绝。
- 提交不是 FILE 类型，或该提交没有可用的 `BOUND` 附件绑定。
- 文件卷未恢复、物理文件损坏，或存储读取失败。

处理方式：

1. 从本人作业历史或教师提交详情页的“下载附件”入口重试，不手工拼接静态地址、内部编号或本地路径。
2. 重新登录，并确认当前作业、提交版本和课程一致。
3. 教师请确认对目标课程仍有管理权限；学生只能下载自己的提交。
4. 页面提示附件不可用或存储失败时，联系运维按部署文档核对 DB-HWK-08、文件卷与备份恢复结果。

### 5.10 评测编译错误或超时

可能原因：

- 代码语言选择错误，或代码无法在对应语言环境编译/运行。
- 输入输出格式与题目要求不一致。
- 程序存在死循环、递归过深或时间复杂度过高。
- 增强 Docker 沙箱不可用，导致系统级评测失败。

处理方式：

1. 查看评测反馈中的编译日志、运行日志、通过用例数和错误类型。
2. 按题目要求修正语言、输入输出格式和边界条件后重新提交。
3. 对超时问题，先在本地用相同样例验证复杂度和终止条件。
4. 若多名学生同时出现系统错误，联系教师或运维排查评测服务状态。

### 5.11 成绩异议不可提交

可能原因：

- 教师尚未发布成绩，学生端还不能发起复核。
- 当前账号不是该课程学生，或访问了未授权课程。
- 已有同一成绩项的待处理异议。
- 复核原因为空、过短或不符合页面校验。

处理方式：

1. 确认成绩页面显示已发布成绩和本人得分明细。
2. 检查是否已有待处理异议，等待教师处理后再根据结果补充沟通。
3. 填写明确的复核原因，例如对应成绩项、疑问点和期望教师核查的材料。
4. 若确认符合条件仍无法提交，联系任课教师检查成绩发布范围和复核状态。

### 5.12 成绩权重或成绩项规则校验失败

可能原因：

- 成绩项名称为空或同一课程下重复。
- 满分不大于 0。
- 权重不在 0 到 1 之间。
- 计入总评的成绩项权重之和超过 1。
- LAB 或 HWK 来源成绩项缺少有效来源任务编号。

处理方式：

1. 回到成绩项配置页 `/courses/9501/grd/grade-items?role=teacher`。
2. 检查每个成绩项的名称、来源模块、来源任务、满分、权重和“计入总评”开关。
3. 点击“校验规则”，按页面错误提示修正。
4. 校验通过后再进入成绩总表同步来源成绩、重新计算和发布。

### 5.13 成绩发布失败、重复发布或无新增发布对象

可能原因：

- 课程尚未配置计入总评的成绩项。
- 仍存在缺失、未提交或待评分成绩，系统拒绝发布。
- 发布范围为空，或包含非本课程成员。
- 同一课程、同一发布范围已经发布过，系统按幂等处理，页面可能返回原发布批次或不产生新的学生可见变化。

处理方式：

1. 在成绩总表中筛选“缺失”“未提交”“待评分”记录，先补齐来源成绩或完成评分。
2. 点击“重新计算”，确认课程总评不再显示不完整状态。
3. 对单个学生发布时，先进入该学生成绩明细，确认其总评已经生成。
4. 查看“发布记录”，确认是否已存在相同范围的发布批次；若已发布，不要重复通知学生，只需让学生刷新成绩页面。

### 5.14 通知投递失败或发布后学生未收到通知

可能原因：

- LRN 通知服务或异步投递任务异常。
- 成绩发布、作业发布或实验发布时没有可通知的课程成员。
- 学生关闭了非必要通知偏好，或通知中心筛选条件隐藏了该通知。
- 发布记录中的通知状态异常，或后台日志记录了通知持久化失败。

处理方式：

1. 教师先确认业务动作已经完成，例如成绩发布记录存在、作业或实训任务状态为已发布。
2. 学生在通知中心清空筛选条件并刷新，同时直接进入对应成绩、作业或实训页面确认业务结果。
3. 若多名学生都未收到通知，教师将课程编号、发布时间和发布记录反馈给管理员。
4. 管理员检查 `/admin/auth` 中用户状态、角色权限和审计日志，并结合后端日志排查 LRN 通知服务。

作业发布的 v2 语义：Homework 与事件 outbox 本地事务成功后即显示为已发布；Learning 或消息 broker 短时不可用不会撤销已发布作业，系统会重试、进入死信队列并对账。只有 Homework/outbox 本地事务失败时发布会返回 `503/HWK_5003`，作业保持草稿。

### 5.15 管理员权限配置错误

可能原因：

- 用户缺少学生、教师或管理员基础角色。
- 角色被停用，或角色权限点被误删、误取消。
- 用户刚调整角色后未重新登录，仍在使用旧会话权限。
- 课程成员角色与平台角色不一致，例如课程助教没有对应平台教师权限或成绩管理权限。

处理方式：

1. 管理员直接访问 `/admin/auth`。
2. 在用户管理区域确认账号状态为启用，并检查用户绑定角色。
3. 在角色管理和权限分配区域确认角色启用，且拥有对应模块权限点，例如课程管理、作业管理、实训管理、成绩管理或审计查看。
4. 调整后要求用户退出并重新登录，再访问目标页面。
5. 若课程内仍无权限，回到课程成员管理确认该用户在目标课程中的成员角色和状态。
