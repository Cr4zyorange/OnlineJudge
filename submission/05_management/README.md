# 05_management 项目管理

正式归档时收录 Notion 项目计划与每日快照、GitHub Project/Issue/PR 证据、分工与轮转记录、站会和小组日报、会议纪要、风险台账、评审与返工记录。

开发期的协作规则正本为 [GitHub 协作与评审规范](../../docs/过程/项目管理/GitHub协作与评审规范.md) 和 [每日站会与汇报工作规范](../../docs/过程/项目管理/每日站会与汇报工作规范.md)。Notion 知识页保持同一规则口径，版本冻结时再导出日报与证据，不在本目录维护重复副本。

建议按 `YYYY-MM-DD/` 保存当日快照，每条证据关联责任人、任务、Issue/PR、完成标准和当日结论，避免只有截图而无法追溯。
